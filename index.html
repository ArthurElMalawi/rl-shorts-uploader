RL Shorts Uploader

Outil personnel de publication de Shorts Rocket League

RL Shorts Uploader est un script Python personnel, exécuté uniquement sur l'ordinateur de son propriétaire. Il publie, une fois par jour, les Shorts Rocket League que le propriétaire monte à partir de ses propres parties, sur ses propres comptes :

  • YouTube : @Azuzti
  • Instagram : @azuzti_the_one
  • TikTok

Il utilise uniquement les API officielles (YouTube Data API v3, Instagram API, TikTok Content Posting API). Il n'a pas d'autre utilisateur, n'est pas distribué et ne collecte aucune donnée.
